# FinalProject_OOP_Kelompok10
## Overview of Lead 4 Dead
Lead 4 Dead adalah game top-down survival shooter bertema zombie apocalypse, dimana player harus bertahan hidup selama mungkin melawan zombie. Player akan diberikan/mencari senjata, yang akan digunakan untuk melawan serangan zombie. Semakin lama player bermain, semakin banyak zombie dan semakin sulit difficultynya dan tipe-tipe zombie baru.  Akan ada items/powerup seperti medkit yang dapat digunakan untuk menambahkan HP player. Backend akan menyimpan highscore player.
